## 术语

### MDF

Mars Development Flow；面向 Git 仓库的版本化文档与交付流程。

### CodeWiki

由 CodeWiki MCP 生成和更新的仓库结构 Wiki。

### ADR

Architecture Decision Record；记录重要且已决定的长期架构取舍及其理由，不描述
当前结构。文件为 `docs/context/adr/<slug>.md`，ID 为 `adr-<slug>`；按主题打开，
不编号。
