# CodeWiki Runtime

由生成、更新入口调用。完成配置后等待用户启用 server；续办时重新检查工具。

## 决策树

```text
┌──────────────────────────────────┐
│ 1 Check tools                    │
└────────────────┬─────────────────┘
                 │
                 ├──── 缺少工具 ────→ 2 Prepare runtime
                 │
                 ▼ 全部可用
                 [返回调用方]

仅步骤 1「缺少工具」进入，不是返回调用方的后续。

┌──────────────────────────────────┐
│ 2 Prepare runtime                │
└────────────────┬─────────────────┘
                 │
                 ├──── 失败/缺失 ────→ [报告并停止]
                 │
                 ▼ 通过
┌──────────────────────────────────┐
│ 3 Verify result                  │
└────────────────┬─────────────────┘
                 │
                 ├──── 失败 ────→ [报告并停止]
                 │
                 ▼ 通过
┌──────────────────────────────────┐
│ 4 Configure host                 │
└────────────────┬─────────────────┘
                 │
                 ├──── 配置失败 ────→ [报告并停止]
                 └──── 配置完成 ────→ [等待启用；续办回 1]
```

## 工作流（唯一执行契约）

读取 `references/codewiki-contract.md` 的八工具清单。

| # | 步骤 | 类型 | 做什么 | 证据 | 通过 → | 失败/缺失 → |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | Check tools | 约束 | 核对本次会话中八工具均实际可调用 | 当前可调用工具清单 | 返回调用方 | 缺工具到 2 |
| 2 | Prepare runtime | 脚本 | 运行 codewiki-runtime 准备源码与运行时 | 退出 0、结构化结果 | 3 | 报告并停止 |
| 3 | Verify result | 约束 | 检查脚本返回的路径和 MCP 字段 | directory、python、mcpServers | 4 | 报告并停止 |
| 4 | Configure host | 约束 | 保留其他配置，添加 MCP 并交接启用 | 配置、启用及续办说明 | 等待启用；续办回 1 | 报告并停止 |

## 术语与数据结构

### 工具与源码

八工具由 `references/codewiki-contract.md` 列出；必须检查本次会话的实际可调用工具，
不能把磁盘安装成功当作工具已启用。缺任何工具时不写目标仓库。

<a id="source"></a>

调用 `python3 "$MDF_ROOT/scripts/mdf.py" codewiki-runtime`；默认安装目录为
`$HOME/.local/share/codewiki`。用户明确另选目录时传 `--directory <绝对路径>`。
脚本只在目录缺失时 clone；目录存在时核对独立 Git 根、源码完整和工作区干净，不 pull、覆盖或清理。
只有 `.venv` 缺失才创建并安装；已有运行时导入失败时停止，不自动重装。

### 运行时与宿主配置

步骤 2 调用脚本一次完成源码与运行时准备；步骤 3 核对退出 0、返回的 directory、python 与 mcpServers。
`codewiki_runtime_failed` 等失败包含命令与退出状态，保留已完成现场并停止，不猜测成功。
宿主设置仍由 Agent 按实际 IDE 格式处理，将脚本返回的 MCP 字段加入已确认宿主，保留其他配置。
安装目录和宿主设置不属于目标仓库产出；不在目标仓库安装运行时。
配置后等待用户启用 server；用户要求续办时回到步骤 1，无需重复命令。
必须重新核对八工具实际可调用，不凭安装、配置成功或用户确认判断工具已就绪。
