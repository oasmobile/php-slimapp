# 临时工作目录

## 用途与布局

- 一次性排查、实验、数据转换与现场辅助脚本统一放在 `.mdf/tmp/<日期>-<主题>/`。
  - 脚本与临时输入、输出放在同一主题目录；需要时用 `input/`、`output/` 分类。
  - 需要说明用途、运行方法或待清理内容时，在主题目录添加 `README.md`。
- 目录按需创建，不要求初始化时建立。

## Git ignore

- 初始化时必须在仓库根 `.gitignore` 中加入 `/.mdf/tmp/`，忽略整个临时目录。
- 已接入项目使用前先确认该规则存在；缺失时补齐，不覆盖已有规则。
- 不提交临时目录及其中的文件。

## 清理与留存

- 工作结束后由执行者清理；中断现场保留，不参与日志与报告的 7 天自动清理。
- 长期复用的脚本移入项目正式目录并纳入 Git；结论和证据归入相应文档或报告。
